# Análisis (Paso 2)

| Análisis | Resultado |
|---|---|
| Tipo de contenido | Narrativo + datos de negocio (historia de marca) |
| Propósito | Información + visualización (mostrar crecimiento y método) |
| Idioma | Español |
| Público | Clientes actuales y potenciales, prensa local, redes sociales |

## Argumentos principales

1. La barbería nació pequeña (1 silla, 2017) y creció a 3 locales.
2. El diferencial es un proceso propio: el **Ritual de 45 minutos**.
3. Los resultados se miden: 78 % retención, 4,9 ★, 1.850 clientes/mes.
4. La digitalización (reservas online, Club Navaja) transformó la experiencia.

## Posiciones donde una imagen aporta valor

| Sección | Por qué | Tipo sugerido |
|---|---|---|
| Intro | Portada emocional: fija identidad de marca | scene |
| Crecimiento | Fechas e hitos → se leen mejor en línea | timeline |
| Los números | 4 métricas → infografía de datos | infographic |
| Antes y después | Contraste directo → comparación | comparison |

Nota: "El Ritual de 45 minutos" sería un `flowchart` ideal, pero `flowchart × screen-print` está marcado como ✗ (no recomendado) en la matriz de compatibilidad. Si se quiere, se hace aparte en estilo `vector-illustration` o `notion`.

## Configuración elegida (Paso 3)

| Dimensión | Elección | Motivo |
|---|---|---|
| Tipo | mixed (scene, timeline, infographic, comparison) | Cada sección tiene una estructura distinta |
| Densidad | balanced (4 imágenes) | Una por sección clave |
| Estilo | `screen-print` | Estética de póster vintage / serigrafía: encaja con la tradición barbera |
| Paleta | Marca propia (rojo barbero + crema + azul marino + dorado) | Colores del poste de barbería + toque premium |
| Idioma de las imágenes | Español | Idioma del artículo |
