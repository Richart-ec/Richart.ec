# Instrucciones para Claude

## Uso de skills: preguntar siempre antes

Antes de usar cualquier skill (herramienta `Skill`), pregunta al usuario y espera su confirmación.

- Indica qué skill quieres usar, para qué y qué va a producir (por ejemplo: "¿Uso `social` para armar el calendario de Instagram?").
- Si hay varias skills posibles, propónlas y deja que el usuario elija.
- Si el usuario dice que no, haz la tarea sin la skill.
- Excepción: si el usuario pide una skill explícitamente (por nombre o con `/nombre-de-la-skill`), úsala sin volver a preguntar.
- Responde siempre en español.
